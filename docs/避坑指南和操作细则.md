## 一、生图：分镜架构（最核心的业务逻辑）

### 1.1 风格锁死

所有生图 prompt 末尾统一追加这段（不改）：

```
Wong Kar-wai film aesthetic, 85mm lens, shallow depth of field,
beautiful bokeh, photorealistic, ultra-high definition, masterpiece,
highly detailed skin texture, rich cinematic contrast,
nostalgic retro film aesthetic
```

代码位置：`backend/services/image_service.py` → `STYLE_BIBLES` 字典

### 1.2 分镜流水线（三步串行，不可并行）

```
Step 0:   extract_visual_context(文案) → 全角色档案文本
Step 0.5a: generate_screenplay(文案 + 角色档案) → JSON {character_cast, scenes}
Step 0.5b: generate_storyboard(screenplay + 句子列表) → JSON {shots[]}
Step 1:   for each sentence → build_single_segment_prompt(storyboard, index)
Step 2:   Fal.ai gpt-image-2 逐张生图
```

**关键数据流**：

`generate_screenplay` 输出：
```json
{
  "face_policy": "show" | "avoid",
  "character_cast": [
    {
      "name": "Li Dacheng",
      "gender": "male",
      "age": "42",
      "appearance": "方脸, 浓眉, 眼角有细纹, 肤色黝黑",
      "clothing": "洗得发白的蓝布中山装",
      "body_type": "瘦削, 肩宽背直",
      "role": "protagonist"
    }
  ],
  "scenes": [
    {
      "emotion": "transition",
      "scene_desc": "1985年深秋, 土坯房前, 一辆二八大杠靠在枣树上...",
      "characters_present": ["Li Dacheng (42)"],
      "location": "农村老家土坯房前院",
      "time": "傍晚"
    }
  ]
}
```

`generate_storyboard` 输出：
```json
{
  "shots": [
    {
      "visual_subject": "Li Dacheng的背影推着二八大杠进村",
      "shot_type": "wide",
      "composition": "Wide establishing shot, back view of a thin man...",
      "emotion": "transition",
      "character_ref": "Li Dacheng (42)"
    }
  ]
}
```

### 1.3 导演 4 原则（注入 generate_screenplay system prompt）

```
=== DIRECTOR'S MANDATE ===
1. 年龄时间线：多年龄角色拆成独立条目，scenes 引用正确版本
2. 时代标记物：每场 scene_desc 含时代视觉锚点（1985→土坯房/二八大杠）
3. 关键道具：跨场景道具保持同一视觉描述
4. 场景连续性：同地点重复出现时锚定固定元素
```

### 1.4 "未知"禁令

角色档案中任何会作为画面主体的角色，`体型/发型/面部/服装` 四个字段绝不允许填"未知"。从身份+时代+场景合理推断。

代码位置：`backend/prompts/image_context.txt`

### 1.5 面孔回避

真实人物传记片：避免正面特写 → 用背影、侧影、剪影、环境空镜、道具特写、局部特写替代。

实现的六种回避方式在 `build_single_segment_prompt` 中，通过 `face_policy` 参数控制。

### 1.6 模型与成本

```
Fal.ai gpt-image-2
quality="low"     # 不要改！medium 贵 8.4 倍
image_size: 2160×3840 (4K超采样) → PIL LANCZOS 缩到 1080×1920
单张: $0.012 (约 ¥0.087)
```

代码位置：`backend/services/image_service.py` → `_generate_fal()`

## 二、剪映 v11 草稿生成（最复杂，逆向工程）

### 2.1 核心铁律：三 ID 必须一致

```
draft_content.json["id"]
  == Timelines/<dirname>/project.json["id"]
  == Timelines 下子目录的名字
```

任何一个不一致 → 剪映不认草稿。

代码位置：`backend/services/jianying_v11_service.py` line 848/867

### 2.2 Y 坐标公式（最容易搞反）

```
JY 坐标系: 中心为原点, Y 轴向上为正
y_jy = 1 - y_px / 960

其中 960 = 画布高度 1920 / 2

例：图片在 1920px 画布中 y=984 位置
y_jy = 1 - 984/960 = 1 - 1.025 = -0.025 ✓

常见错误：写成 y_px/960 - 1 → 图片飞到屏幕外
```

实际使用的 Y 坐标：
| 元素 | y_px | y_jy | 说明 |
|------|------|------|------|
| 内容图片 | 984 | -0.025 | 1080×1214 图在 1080×1920 画布中 |
| 上遮盖条 | 188.5 | +0.804 | 1080×377, y=0 |
| 下遮盖条 | 1755.5 | -0.829 | 1080×329, y=1591 |
| 字幕 | 1269 | -0.32 | V5 bench 对齐 |
| 标语 | 1651 | -0.72 | 行楷金色 |
| 标题金 | 259 | +0.73 | 第二行 |
| 标题白 | 150 | +0.844 | 第一行（仅拆分时）|
| 声明 | 1774 | -0.85 | 底部低对比小字 |

### 2.3 anim_offset：视频动画必须跳在文字动画之后

```
material_animations 数组：
  [0..text_anim_count-1]  文字动画（模板原带的）
  [text_anim_count..]      视频动画（新增的）
  
anim_offset = text_anim_count  // 传给 _build_video_refs
```

**为什么**：模板里文字动画排在视频动画前面。新增的视频动画追加在数组末尾，但文字动画索引不变。如果不传 anim_offset，视频段引用的是文字动画，效果全乱。

代码位置：`jianying_v11_service.py` line 635-636

### 2.4 三 ID 同步规则

每个 segment 中：
```
segment["material_id"]  = draft["materials"]["videos"][vid_idx]["id"]
                                    ↓ 同一个 ID 必须出现在 ↓
segment["extra_material_refs"][3]   // material_animations 中对应项
segment["extra_material_refs"][0..7] // 每个辅助材料数组的对应项
```

代码位置：`jianying_v11_service.py` line 670-674

### 2.5 模板操作规则

```
✅ 可以：
  - deepcopy 模板 → 在新草稿上改
  - in-place 修改 materials 和 segments
  - append 新增的段/材料
  - 新增 track

❌ 禁止：
  - 删除模板原有 materials 条目（track 用 ID 引用了它们）
  - 整数组替换（必须 in-place 修改或逐个 append）
  - 修改 track 的 type 字段
```

### 2.6 遮盖条架构（8 轨）

```
track[0] = video     — 内容图片 (1080×1214, y=-0.025, Ken Burns)
track[1] = video     — 上遮盖条 (1080×377, y=+0.804, 静止)
track[2] = video     — 下遮盖条 (1080×329, y=-0.829, 静止)
track[3] = text      — 字幕 (y=-0.32)
track[4] = text      — 声明 (y=-0.85)
track[5] = text      — 标语 (y=-0.72)
track[6] = text      — 标题金 (y=+0.73)
[track[7]] = text    — 标题白 (y=+0.844, 动态插入，仅拆分时)
track[7|8] = audio   — 配音
```

**遮盖条原理**：图片做 Ken Burns 放大动画时，放大后的图片会溢出到上下装饰区域。上下遮盖条是纯藏青色块（#071730），盖住溢出的画面，同时自带暖白线提供装饰效果。遮盖条本身不做动画。

### 2.7 meta_info 必须解密→改值→加密

```python
# 1. 解密模板 meta_info
dm = _decrypt_file("draft_meta_info.json")  # jy-draftc -d

# 2. 修改
dm["draft_id"] = new_id
dm["draft_name"] = draft_name
dm["draft_fold_path"] = draft_dir
dm["tm_draft_create"] = now_microseconds

# 3. 回写明文 JSON
json.dump(dm, ...)

# 4. 加密
_encrypt_file(dm_path)  # jy-draftc -e
```

### 2.8 草稿注册

`root_meta_info.json`（明文，不用加密）的 `all_draft_store` 数组中插入：
```json

  "draft_id": "V11-xxxxxxxx",
  "draft_fold_path": "E:/.../JianyingPro Drafts/DraftName",
  "draft_cover": ".../draft_cover.jpg",
```

### 2.9 草稿目录结构

```
JianyingPro Drafts/<草稿名>/
├── draft_content.json      ← 加密
├── draft_meta_info.json    ← 加密
├── draft_settings          ← 加密

├── Resources/

│   ├── cover_top.png       ← 上遮盖条 (1080×377)

```

### 2.10 加密方式

用剪映自带的 `jy-draftc` 工具：
```bash
# 解密
jy-draftc -d encrypted.json decrypted_tmp.json

# 加密
jy-draftc -e plain.json  # 输出到 plain.json.enc.json
```

环境变量 `JY_INSTALL_DIR` 必须指向剪映安装目录。

## 三、TTS 火山引擎（一个关键坑）

### 3.1 错误响应格式陷阱

火山引擎 TTS API 返回**两种不同格式**，即使是 HTTP 200：

**成功时**（流式 NDJSON）：
```
{"header":{"code":0},"data":"base64chunk..."}
{"header":{"code":0},"data":"base64chunk..."}
{"header":{"code":20000000}}  ← EOF
```

**错误时**（单行 JSON，不是流式！）：
```json
{"code":45000292,"message":"quota exceeded","reqid":"..."}
```

**修复**：在逐行解析之前的开头加判断：
```python
resp_text = resp.text.strip()
try:
    top_level = json.loads(resp_text)
    err_code = top_level.get("code", 0)
    if err_code and err_code != 0:
        print(f"API错误 code={err_code}")
        return None
except json.JSONDecodeError:
    pass  # 正常流式，继续逐行解析
```

不修的话：流式解析遍历每行 → 找不到匹配 chunk → 静默返回空音频 → 降级 edge-tts。

代码位置：`backend/services/volc_tts_v3_service.py` line 128-137

### 3.2 音色配置

```python
VOLC_VOICES = {
    "vc_shuangsisi":   "zh_female_shuangkuaisisi_uranus_bigtts",  # 预设音色
    "vc_clone_female": "SILICONFLOW_CLONE",                       # 女声复刻
    "vc_clone_wanglq": "S_xxxxxxxxxxxxx",                          # 王立群复刻（替换为你的 speaker ID）
}
```

复刻音色用 `resource_id="seed-icl-2.0"`，预设音色用 `"volc.seedtts.default"`。

## 四、前置准备：创建剪映模板（必须先做！）

没有模板，整个 v11 草稿导出流程跑不了。代码通过 deepcopy 模板来生成每个草稿，所以必须先有一个结构完整的模板。

### 4.1 模板要求

模板是一个剪映 v11 草稿，包含 **6 条轨道**（代码运行时会动态插入 2 条遮盖条轨，变成 8 轨），各项数量精确：

| 项目 | 数量 | 说明 |
|------|------|------|
| 视频轨 (track[0]) | 1 段 | 一张占位图片，1080×1214，居中偏上 |
| 字幕轨 (track[1]) | **14 段** | 每段写"字幕"二字即可 |
| 声明轨 (track[2]) | 1 段 | 底部小字，如"图片由AI生成" |
| 标语轨 (track[3]) | 1 段 | 如"- 品读传奇人生 -" |
| 标题轨 (track[4]) | 1 段 | 如"标题" |
| 音频轨 (track[5]) | 1 段 | 0.5 秒静音音频 |
| materials["videos"] | **3 个** | 图片材料 |
| materials["texts"] | **17 个** | 文字材料（14 字幕 + 3 标题/标语/声明）|
| materials["audios"] | 1 个 | 音频材料 |

**14 段字幕 + 17 个文字材料 + 3 个视频材料是硬性要求。** 代码会在这些模板位上 in-place 修改，数量不对就会数组越界。

### 4.2 操作步骤（在剪映内完成）

**1）新建项目**
- 打开剪映 v11，新建草稿
- 画布：1080×1920（9:16 竖屏），30fps

**2）创建轨道结构**（按从上到下排列）

| 轨道 | 操作 |
|------|------|
| **标题轨** | 添加文本"标题"，放到画面顶部偏下（y≈259），金色 |
| **标语轨** | 添加文本"- 品读传奇人生 -"，放到图片下方（y≈1651），金色行楷 |
| **图片/视频轨** | 添加一张 1080×1214 的占位图（纯藏青色 #071730），居中偏上（y≈377） |
| **字幕轨** | 添加 **14 段**文本，每段写"字幕"，放到画面中下部（y≈1269），白色带黑描边 |
| **声明轨** | 添加文本"图片由AI生成与网络下载\n科普视频 无不良引导"，放到底部（y≈1774），低对比灰 |
| **音频轨** | 添加一段 0.5 秒静音音频 |

**3）补足 materials 数量**
- 再往项目里拖入 2 张任意图片（总共 3 个视频材料）→ 然后从时间轴上删掉多余的段，只保留一张图在轨道上。删段不删材料，materials 里仍保留 3 个。
- 字幕轨上刚好 14 段文本（不够就多复制几个"字幕"段）

**4）保存并关闭剪映**

**5）找到草稿目录**
- 打开 `E:\360Downloads\JianyingPro Drafts\`（或你安装剪映时设置的草稿目录）
- 找到刚创建的那个草稿文件夹，改名为 `Template_v11_6T`

**6）安装字体**
- 把 `fonts/XianKai_Title.otf`（思源宋体 Heavy）和 `fonts/Slogan_Xingkai.ttf`（行楷）复制到：
  `JianyingPro/11.0.0.14274/Resources/Font/` 目录下
- 这两个字体文件可以从项目仓库 `fonts/` 目录获取

### 4.3 修改配置路径

创建完模板后，根据你的实际目录修改 `backend/services/jianying_v11_service.py` 顶部这几行：

```python
JY_INSTALL_DIR = r"你的剪映安装目录"
DRAFT_ROOT = r"你的剪映草稿目录"
TEMPLATE_DIR = r"你的剪映草稿目录/Template_v11_6T"
REGISTRY_PATH = r"C:\Users\你的用户名\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\root_meta_info.json"
```

### 4.4 验证模板

```bash
# 用剪映自带的工具解密模板，检查结构
jy-draftc -d "你的草稿目录/Template_v11_6T/draft_content.json" temp.json
# 检查 temp.json 中：
# - tracks[1].segments 长度 = 14
# - materials.texts 长度 = 17
# - materials.videos 长度 >= 3
# 确认无误后删除 temp.json
```
